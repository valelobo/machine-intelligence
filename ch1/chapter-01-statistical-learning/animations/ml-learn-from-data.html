1. Computational Thinking

    Resolver problemas como um cientista da computação: decomposition, pattern recognition, abstraction e algorithms.

  2. a. Classical CT

    Uma pessoa decompõe o problema e escreve as regras (o algoritmo). O computador as aplica aos dados e devolve uma saída.

  3. Onde o clássico falha

    Para imagens, sons ou textos, ninguém consegue escrever as regras explicitamente.

  4. b. Intelligent CT

    Invertemos a lógica: fornecemos os dados e as saídas desejadas (training data), e o computador aprende as regras.

  5. As regras são aprendidas

    O training encontra os pesos w do modelo. Esses pesos são as regras aprendidas.

  6. Aplicar a dados novos

    No testing, dados nunca vistos (test data) entram junto com as regras aprendidas.

  7. O quadro completo

    No classical CT escrevemos as regras; no intelligent CT elas são aprendidas dos dados e depois usadas como um programa comum.
