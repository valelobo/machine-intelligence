1. Pensamento computacional

    Resolver problemas como um cientista da computação: decompor o problema, reconhecer padrões, abstrair e escrever um algoritmo.

  2. Programação tradicional

    Uma pessoa escreve as regras. O computador as aplica aos dados e devolve uma saída.

  3. Onde isso falha

    Para imagens, sons ou textos, ninguém consegue escrever as regras explicitamente.

  4. Aprender com exemplos

    O aprendizado de máquina inverte a lógica: fornecemos os dados e as saídas que desejamos.

  5. As regras são aprendidas

    O treinamento encontra pesos w que levam as entradas às saídas. Esses pesos são o modelo.

  6. Aplicar a novos dados

    Dados de teste, nunca vistos, entram junto com as regras aprendidas.

  7. O quadro completo

    Depois de treinado, o modelo funciona como um programa comum: dados + regras aprendidas geram a saída.
