1. Traditional programming

    A programmer writes the rules. The computer applies them to data and returns an output.

  2. Where it breaks down

    For images, sound or text, nobody can write the rules down explicitly.

  3. Learn from examples

    Machine learning turns it around: we supply data and the outputs we want.

  4. The rules are learned

    Training finds weights w that map inputs to outputs. Those weights are the model.

  5. Apply to new data

    Unseen test data goes in together with the learned rules.

  6. The full picture

    Once trained, the model works like an ordinary program: data + learned rules give the output.
