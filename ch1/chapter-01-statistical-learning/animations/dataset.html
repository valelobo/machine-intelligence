1. Um dataset é uma tabela

    5 pessoas, 3 informações sobre cada uma e a renda que queremos prever.

  2. Linha = observação

    Cada linha i é uma observação: o vetor de features xᵢ e sua resposta yᵢ.

  3. Coluna = feature

    Cada coluna j é uma variável de entrada xj, medida em todas as n observações.

  4. A matriz X

    Juntando as features de todas as observações: uma matriz com n linhas e p colunas.

  5. O vetor y

    As respostas formam um vetor com n entradas, uma por linha de X.

  6. Uma entrada xij

    O valor da feature j na observação i. Primeiro índice: linha; segundo: coluna.

  7. Um ponto novo

    Uma pessoa que não está nos dados: conhecemos x₀, mas não y₀. É isso que o modelo deve prever.

  8. A notação daqui em diante

    O training data é o par (X, y). O modelo aprende com ele e é usado em pontos novos.
