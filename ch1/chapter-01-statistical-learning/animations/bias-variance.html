1. Expected test error

    For a test point x₀ the expected error splits into three parts. We plot each one against model flexibility.

  2. Squared bias

    Error from approximating a complicated problem with a simple model. It falls as the model gets more flexible.

  3. Variance

    How much f̂ would change on a different training set. Flexible models follow the noise, so variance grows.

  4. Irreducible error

    Var(ε) is noise that no model can remove. It is a floor under the test error.

  5. The sum: test MSE

    E(y₀ − f̂(x₀))² = Var(f̂(x₀)) + Bias(f̂(x₀))² + Var(ε). Adding the curves gives a U shape.

  6. The trade-off

    The best model balances bias and variance. Too simple underfits; too flexible overfits.
