Machine learning em contexto

  1. Ciência da Computação

    Algoritmos, programação e sistemas: como fazer o computador executar uma tarefa.

  2. Estatística

    Como aprender com dados quando há incerteza e ruído.

  3. Domínio de aplicação

    A área em que o problema real existe: engenharia, saúde, economia…

  4. Artificial Intelligence

    Sistemas que realizam tarefas que pareceriam exigir inteligência. Fica no encontro entre computação e estatística.

  5. Machine Learning

    Um subconjunto da IA: sistemas que aprendem as regras a partir de dados.

  6. O quadro completo

    ML ⊂ IA, e o ML vive onde computação, estatística e domínio de aplicação se encontram.

  1. Programação

    Escrever código: algoritmos, estruturas de dados e software.

  2. Matemática e Estatística

    Álgebra linear, probabilidade, otimização e inferência.

  3. Domínio de aplicação

    Conhecer a área em que os problemas reais aparecem.

  4. Machine Learning

    Nasce do encontro entre programação e matemática/estatística.

  5. Engenheiro(a) de software

    Programação + domínio: constrói sistemas, sem necessariamente modelar dados.

  6. Cientista tradicional

    Matemática/estatística + domínio: modela fenômenos, com menos foco em código.

  7. Cientista de dados / ML

    No centro: combina as três competências.

  8. O quadro completo

    Cada perfil profissional nasce de uma combinação diferente dessas competências.
